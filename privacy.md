# Openclaw privacy policy

Last updated: 9 October 2026

**Who uses it.** Openclaw is used by one person, Robert Projkovski, with Robert's own Google account. There are no other users.

**What it accesses.** With Robert's consent on Google's sign-in screen, Openclaw can read, label and draft messages in Robert's Gmail and read and create events in Robert's Google Calendar. It uses this data only to carry out Robert's own requests.

**Processing.** To answer a request, the relevant text may be sent to the AI model provider the assistant uses (Anthropic). The data is not used for advertising and is not sold or shared with anyone else.

**Storage.** Sign-in tokens and working notes stay on Robert's own private server at home.

**Google user data.** Openclaw's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

**Removing access.** Access can be revoked at any time at https://myaccount.google.com/permissions.

**Contact.** Through the support address shown on Google's sign-in screen for this app.
